# Chrome 扩展安装与使用

适用于桌面版 Chrome。普通使用者不需要 Python、Node.js、GPT/DeepSeek 账号或 API 密钥。目前通过“加载已解压的扩展程序”安装，不是 Chrome 应用商店版本。

## 1. 解压并找对文件夹

从维护者提供的项目 ZIP 或扩展 ZIP 解压到一个准备长期保留的位置。不要直接选择 ZIP，不要把安装目录放进会自动清理的临时文件夹。

需要选择的目录结构如下：

```text
chrome_extension/       ← 在 Chrome 中选择这一层
├── manifest.json       ← 打开文件夹就能看到
├── background.js
├── content.js
├── core.js
├── adapter.js
└── data/
    └── answer-pack.json
```

如果使用整个项目包，不要选择最外层 `research-knowledge-helper`。如果提示找不到 manifest，通常是选错了目录层级，或还没有解压。

## 2. 加载扩展

1. 在 Chrome 地址栏手动输入 `chrome://extensions/`，按回车。
2. 开启页面右上角“开发者模式”。
3. 点击左上角“加载已解压的扩展程序”。
4. 选择上一步的 `chrome_extension` 文件夹。
5. 确认出现“科研资料助手 · 本地题库”卡片，并且开关已开启。
6. 可选：点击浏览器工具栏的拼图图标，将“科研资料助手”固定到工具栏。

加载方式与更新步骤依据 [Chrome 官方扩展教程](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)。安装通常不需要重启浏览器。

如果单位管理的 Chrome 不允许开启开发者模式，请联系管理员确认安装方式，不要修改企业安全策略。工具栏固定图标只用于快速打开入口，不决定页面面板是否显示。

## 3. 在问卷页面使用

1. 打开项目 README 列出的已适配问卷。已开着的页面需要刷新一次。
2. 在右上角“科研资料助手”中填写自己的姓名、班级。
3. 点击“检查题目”，扩展会匹配并自动填写已收录题目。
4. 等待“已填写 X/Y 题”。每次实际操作有约 250–650 毫秒间隔；填写时不要刷新页面。
5. 下方“未匹配题目”只列出未匹配题号、题干和原因；全部匹配时显示“无”。未匹配题已有的手动输入会保留。
6. 核对网页实际填写结果。点击“收起”可折叠面板，再点“展开”恢复。

检查填写与提交是两个步骤。只有全部匹配、身份和题目未改变、实际填写通过核验时，“提交”才会启用。点击它会通过网页正常提交，并在网站留下答卷记录。只想检查或练习时，停在填写阶段即可。

有未匹配项时，即使你手动答完这些题，扩展仍不会把它们当成有据匹配答案，提交按钮仍禁用。需要扩展自动处理时，先依据可靠资料补库并重建；也可自行决定通过网站原生按钮提交。

同一姓名、班级与问卷一旦由扩展尝试提交，就会写入本机防重复锁。遇到网络异常、验证码或网站拒绝时不会自动再次提交；先查看网页实际状态。验证码由使用者自己处理。

## 4. 更新版本或题库

1. 将新版文件解压到原安装目录，或用新版完整文件覆盖原目录。
2. 在 `chrome://extensions/` 找到扩展，点击卡片上的“重新加载”图标。
3. 回到问卷页面并刷新。内容脚本和答案包不会自动更新到已经打开的页面。
4. 核对面板显示的新版本，然后重新检查题目。

用原目录更新并重新加载通常能保留本机记录；更换安装目录可能生成新的扩展身份，从而无法读取旧记录。更新前先核对网页提交状态，避免重复提交。

## 5. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 没有助手面板 | 确认扩展开启、网址属于适配入口；重新加载扩展后再刷新网页 |
| 找不到 manifest | 确认已经解压，选择直接包含 `manifest.json` 的文件夹 |
| 提示题量或编号异常 | 网站结构可能改变；保留原页面，提交去身份的最小例子给维护者 |
| 有几题没有匹配 | 其他匹配题仍可填写；按面板题号核对，不能凭相似题猜答案 |
| 检查按钮暂时不可用 | 正在填写时会暂时禁用；请等待当前操作结束 |
| 填写完成但提交按钮不可用 | 有未匹配题、解析错误、身份变化或已尝试提交时都会阻止提交 |
| 后台填写较慢 | Chrome 可能限制后台计时，等到显示核验完成再继续 |
| 更新后还是旧答案 | 两步都要做：扩展管理页“重新加载”，问卷页“刷新” |
| 姓名或班级不能退格删除 | 更新至最新版，重新加载扩展并刷新问卷；旧面板不会自动替换 |
| 面板出现两份 | 可能同时加载了旧版和新版；在扩展管理页停用其中一份 |
| 显示已经尝试提交 | 先查看网页结果，扩展不会自动解锁重试 |

## 6. 卸载

在扩展管理页点击“移除”可以卸载。卸载或清理扩展存储会失去本机提交记录和防重复锁。完整数据流见[隐私说明](PRIVACY.md)。
