# 数据与第三方材料许可

## 代码与数据分开

根目录 `LICENSE` 的 MIT 许可覆盖本项目的软件代码及项目自写使用文档，不包括题目、整理答案、规章原文、第三方摘要与引用内容。

以下目录属于资料范围：`knowledge_base/data/`、`knowledge_base/sources/`、`knowledge_base/questions/`、`knowledge_base/exports/`，以及生成的 `chrome_extension/data/answer-pack.json`。不因转换为 Markdown 或 JSON 而改变原有权利归属。

## 维护者审阅项目

公开前确认拟分发文本、题目和原单位资料可否再分发，必要时取得授权或改为仅保留官方链接和使用者自行导入。不应只在 README 加免责声明就把未获授权的材料改标为 MIT。

项目保留去身份的文本数据，源代码和资料可以分开发布。打包脚本只生成本地 ZIP，不会调用 GitHub、自动创建公开 Release 或自动上传资料；对外发布由维护者明确执行。

权利人如对引用或分发有异议，可向未来仓库维护者提出具体来源和记录ID；公开问题描述中无需提供个人身份证明或私人答卷。
