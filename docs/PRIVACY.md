# 隐私与数据流

## 随项目分发的内容

项目分发源代码、整理后的题目与参考条文、来源目录、离线示例和构建脚本。公开候选版不分发个人姓名/班级、私人答卷、判分截图、签名结果链接、浏览器记录导出、原始PDF或图片，也不包含从私人测试数据重建资料的脚本。

部分题目最初来自非公开整理材料。公开候选版只保留题目、整理答案和来源编号，删除个人选择、判分文本、截图文件名、坐标和测试轮次。`curated_note_answer` 表示整理笔记中的答案，不能理解为公开可复查的网页评分。

官方作者署名、机构名称和公开出处属于引用信息；不将它们伪装成项目作者，也不移除必要的文献归属。资料授权独立于隐私清理，见[数据许可](DATA_LICENSE.md)。

## 扩展运行时

| 数据 | 去向和用途 |
| --- | --- |
| 内置答案包 | 从扩展自己的文件加载，在本地匹配 |
| 网页题目、选项 | 在当前页面分析；点击检查不会发送给模型或项目服务器 |
| 用户填写的姓名、班级 | 写入当前问卷页面；目标网站可以读取页面表单内容 |
| 点击扩展提交 | 使用网站正常按钮，向问卷平台提交表单 |
| 提交尝试和反馈 | 写入 `chrome.storage.local`，含身份、题目、答案、时间及可见结果文本 |
| 资料库中的官方链接 | 使用者主动打开时由浏览器访问目标网站 |

扩展没有模型请求、遥测、远程日志、远程代码或同步存储；权限仅为 `storage`。内容脚本只匹配清单中配置的问卷入口和结果页。在其他问卷的结果页上，若无对应配置和提交记录，不记录为本扩展的新结果。

扩展不自动提交。即使不点击提交，姓名和班级一旦填入第三方网页，也不能假定网站无法读取。测试功能时使用虚构示例并停在本地控件测试页面；不要用他人的身份产生答卷。

## 本机记录的保留

提交锁基于问卷、姓名和班级生成摘要；完整身份仍保存在本机提交记录中，所以这不是匿名存储。记录没有自动到期机制，精简面板不提供导出或 JSON 查看按钮。卸载扩展或清除其本地存储会失去记录及防重复保护；清理前先核对实际提交状态。

项目不负责保存使用者的导出文件。反馈问题时请仅提供匿名最小例子，删除身份、题面中的私人信息及所有结果页令牌。
